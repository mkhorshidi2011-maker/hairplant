# فاز ۶ — استقرار و تحویل

فایل `PROJECT_BRIEF.md` را بخوان (بخش‌های ۴ و ۱۳). فاز ۵ تأیید شده است. **فقط کارهای همین فاز را انجام بده.**

## کارها

1. `Dockerfile` چندمرحله‌ای برای تولید و `docker-compose.yml` شامل app، postgres و reverse proxy (Caddy یا Nginx) با HTTPS. تمام تصاویر و وابستگی‌ها باید بدون اینترنت بین‌الملل قابل build و اجرا باشند (به نکته mirror های npm و Docker در README اشاره کن).
2. متغیرهای محیطی تولید، مدیریت secret ها، و health-check برای app و دیتابیس.
3. اجرای خودکار migration ها در استقرار.
4. اسکریپت backup روزانه دیتابیس (`pg_dump` با نگهداری چند نسخه آخر) و راهنمای restore.
5. تنظیم هدرهای امنیتی (CSP سازگار با پروژه، HSTS، X-Content-Type-Options و مانند آن) و فشرده‌سازی.
6. `README.md` **فارسی** کامل:
   - راه‌اندازی توسعه و تولید
   - توضیح متغیرهای محیطی
   - افزودن مقاله، روش، گالری و FAQ
   - **جایگزینی رسانه‌ها** (`media:report`، قرار دادن فایل با نام اسلات، `media:sync`، `media:check`)
   - ساخت ادمین، backup و restore، به‌روزرسانی
7. نهایی‌کردن `TODO_CONTENT.md`: فهرست همه placeholder های متن و رسانه که باید پر شوند (نام پزشک، شماره نظام پزشکی، مجوزها، آدرس، تلفن، آمار واقعی، نظرات، تصویرها و ویدیوها).
8. فهرست کنترل پیش از انتشار (checklist) در README.

## معیار پذیرش

- یک دستور واحد (`docker compose up -d`) کل سیستم را بالا می‌آورد.
- migration و ساخت ادمین بدون دستکاری دستی ممکن است.
- مستندات کامل و `TODO_CONTENT.md` نهایی است.
