# فاز ۴ — رزرو، دیتابیس، پیامک و پنل ادمین

فایل `PROJECT_BRIEF.md` را بخوان (بخش‌های ۴، ۶ و ۷). فاز ۳ تأیید شده است. **فقط کارهای همین فاز را انجام بده.**

## کارها

1. Prisma + PostgreSQL: مدل‌های `Reservation`، `ContactMessage`، `AdminUser` طبق بخش ۷ و migration ها.
2. `/reservation`: فرم کامل طبق بخش ۶ با React Hook Form + Zod. اعتبارسنجی شماره موبایل ایران، چک‌باکس رضایت، و پیام موفقیت با **کد پیگیری**.
3. Server Action یا Route Handler امن: اعتبارسنجی مجدد سمت سرور، تمیزسازی ورودی، **honeypot**، **rate-limit** بر اساس IP (ذخیره‌شده به صورت hash) و شماره موبایل.
4. لایه `SmsProvider` با دو پیاده‌سازی: `ConsoleSmsProvider` (پیش‌فرض در development) و یک درگاه ایرانی (کاوه‌نگار یا قاصدک، با کلیدها در env). پیامک تأیید به بیمار و اعلان به کلینیک. خطای ارسال پیامک نباید ثبت رزرو را خراب کند، فقط لاگ شود.
5. فرم `/contact-us` را به `ContactMessage` وصل کن (با همان محافظت‌ها).
6. `/admin`: ورود با ایمیل و رمز (هش با argon2 یا bcrypt)، نشست امن با کوکی httpOnly و SameSite، محافظت میان‌افزاری از همه مسیرهای admin. صفحات: فهرست رزروها (فیلتر وضعیت و تاریخ جلالی، جستجو)، جزئیات و تغییر وضعیت (جدید، تماس گرفته شد، قطعی، لغو)، یادداشت داخلی، فهرست پیام‌های تماس، **خروجی CSV**.
7. اسکریپت `pnpm admin:create` برای ساخت کاربر ادمین از خط فرمان.
8. تست‌های واحد برای validator ها، rate-limit و منطق وضعیت.
9. `.env.example` را کامل کن.

## معیار پذیرش

- مسیر کامل: ثبت رزرو، ذخیره در DB، نمایش در ادمین، تغییر وضعیت، خروجی CSV.
- بدون ورود، هیچ مسیر admin در دسترس نیست.
- تست‌ها سبز و `lint`، `typecheck` و `build` بدون خطا.

## پایان کار

گزارش با فرمت بخش ۱۴ و منتظر تأیید بمان.
